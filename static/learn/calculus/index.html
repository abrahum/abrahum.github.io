课本从定义开始，
当年的人从难题开始

极限的定义在课本第一章第一节，而柯西写下接近它的句子，是 1821 年。

在柯西之前的一个半世纪里，牛顿、欧拉、拉格朗日都在用微积分算东西，只是谁也说不清自己究竟在算什么。

把这段历史倒过来读，公式会变得好懂。牛顿要的是瞬时速度，他手上没有极限；费马想知道曲线哪一点最高，也从没操心过连续性；傅里叶说任何曲线都能写成三角级数，拉格朗日当场就反对。

这本书按问题重排同样的内容。先看一个人为什么非做这件事，再看他的办法被后人挑出什么毛病，最后才落到课本上那条定义。毛病被挑出来的地方，往往就是考试最容易错的地方。

章节顺序跟教材一致，从函数与极限一路排到无穷级数。你可以正着读，也可以在复习时直接翻到某一章，只读它的「源头」和「怎么算」两节。每章末尾的习题分三档，A 档练定义，B 档接近考试，C 档是从论文里找出来的原题。

看之前先说三件事

记号跟同济教材一致，习题分三档，每道题的答案都折叠着，先自己动手再点开。

哪些记号跟教材一样

ε 和 δ 的用法、\(\mathrm{d}x\) 与 \(\Delta x\) 的区别、\(f'(x)\) 与 \(\mathrm{d}f\) 什么时候用哪个，都照教材来。每章第一次出现新记号时会解释一句，不认识的符号可以在那一节里找。

三档习题分别练什么

A 档练定义和基本计算，一题五分钟能做完；B 档是综合题，难度接近期末考试和考研；C 档大多是从某位数学家的论文里找出来的原题，做不出来可以先看答案里的思路。最后还有几道思考题，只给提示，没有标准答案。

图是怎么画出来的

全站的图都是脚本按真实函数值算出来再画的，没有示意图。曲线是普鲁士蓝，辅助线和标注用墨灰，填充越深表示累积得越多。改了函数就能重画，脚本放在 tools 目录里。
