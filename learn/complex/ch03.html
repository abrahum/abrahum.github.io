第三章1825 年至 1886 年

复积分与柯西定理

这一章要算一个复变函数沿曲线累加的结果。定义跟实积分一样，可算完会碰上实积分里没有的事：同一个函数从同一点走到同一点，换条路，答案就变了。柯西 1825 年给出了答案不变的条件，条件里只看函数在区域里解不解析，不看曲线长什么样。

复积分的定义是把曲线切成小段，每段乘上函数值再相加，跟实积分的黎曼和没什么两样。麻烦出在算出来的结果上：同一条曲线的起点终点不变，换一条路走，积分可以完全不同，这让复积分没法照搬实积分那套直接算。柯西 1814 年把这件事写成报告，1825 年刊出，第一次说清了积分与路径无关的条件，后面每个定理都要用到它。

一、把曲线切成小段

设 C 是复平面上一条有向曲线，起点 A、终点 B，f 在 C 上有定义。把 C 沿自己的方向依次取分点 \(z_0=A,z_1,\dots,z_n=B\)，在每一小段上任取一点 \(\zeta_k\)，作乘积 \(f(\zeta_k)\Delta z_k\) 并全部加起来，得到一个复数；让分点越来越密，最大的弧长 \(\lambda\) 趋于零，如果这些和都趋向同一个确定的复数，就说 f 沿 C 可积，那个极限叫 f 沿 C 的积分。

定义里唯一要留神的地方在 \(\Delta z_k\) 上：它带方向，可以取负，所以每个乘积都是复平面里的一根小向量，全部加起来要按向量的规矩相加。图里左边把曲线切成 6 段，右边把这些小向量逐段首尾相接，从起点接出来的合向量就是积分的近似值，段数加多，合向量就稳定下来，不再乱跑。

定义（复积分）

设 C 为起点 A、终点 B 的有向曲线，用分点把 C 分成 n 段，第 k 段上任取一点 \(\zeta_k\)，作和 \(S_n=\sum_{k=1}^{n}f(\zeta_k)\Delta z_k\)。当最大弧长 \(\lambda\to0\) 时 \(S_n\) 趋于定值 I，则称 f 沿 C 可积，I 叫 f 沿 C 的积分，记作 \(\int_C f(z)\,dz\)。若 C 分段光滑、f 在 C 上连续，这个积分一定存在。

要真算一个积分，得先把曲线写成参数式。设 \(C:z=z(t)\)，\(\alpha\le t\le\beta\)，\(z'(t)\) 连续，那么 \(\Delta z_k\) 就换成 \(z'(t)dt\)，复积分变成一个实变量的复值积分，对 t 直接算就行。把实部虚部分开还能得到另一副面孔，\(\int_C f\,dz=\int_C(u\,dx-v\,dy)+i\int_C(v\,dx+u\,dy)\)，它把复积分拆成两个实的第二类曲线积分，第二章的柯西-黎曼方程从这里能看出点影子。

定理（复积分的计算）

设 \(C:z=z(t)=x(t)+iy(t)\)，\(\alpha\le t\le\beta\)，\(z'(t)\) 连续且不为零，\(f=u+iv\) 在 C 上连续，则

\[ \int_C f(z)\,dz=\int_\alpha^\beta f[z(t)]\,z'(t)\,dt. \]

右端是实变量 t 的积分，按实部虚部分开算即可。

三条性质跟着定义就来。线性是显然的：\(\int_C(\alpha f+\beta g)dz=\alpha\int_C f\,dz+\beta\int_C g\,dz\)。方向性也不难：把曲线反过来走，每一段的 \(\Delta z_k\) 都变号，所以 \(\int_{C^-}f\,dz=-\int_C f\,dz\)。第三条最常用，叫估值不等式，\(\left|\int_C f\,dz\right|\le\int_C|f|\,|dz|\le ML\)，其中 M 是 |f| 在 C 上的最大值，L 是 C 的长度。第五章把实积分换成复积分来算的时候，收尾全靠这一条。

为什么乘的是 Δz_k 而不是弧长

实积分乘的 \(\Delta x\) 恒为正，所以积分值一定夹在上下界之间。复积分的 \(\Delta z_k\) 带方向，同一条曲线换个走法就变号，两段的贡献能互相抵消，积分因此可以是零，也可以不是实数，\(1/z\) 沿单位圆一圈得到 \(2\pi i\) 就是例子。带方向是复积分与实积分的第一处差别。

二、柯西积分定理

算几个例子会碰上一件怪事：\(f(z)=z\) 沿任何闭路走一圈的积分都是零，\(f(z)=1/z\) 绕原点一圈却得到 \(2\pi i\)。前者在整个平面上处处可导，后者在原点没有定义。柯西看出这不是巧合，只要函数在区域里处处可导，闭路上的积分就只能是零，这条结论叫柯西积分定理，是整章的地基，后面每个定理都要靠它。

定理（柯西积分定理）

设 f 在单连通区域 D 内解析，C 是 D 内任意一条简单闭曲线，则

\[ \oint_C f(z)\,dz=0. \]

把 C 换成 D 内任意一条复合闭路，结论同样成立。

证明的办法是把区域切碎。用有限条横线和竖线把 D 分成一堆小方格，压在外边界上的那几块再补几刀切成更小的块，总之让每一块都整个躺在 D 里，而且直径可以任意小。对每一块取沿它边界逆时针一圈的积分，再全部加起来：内部的公共边被相邻两块各走了一次，方向一正一反，两次的积分互相抵消，最后只剩最外面那一圈 C。这一步只跟记账有关，跟 f 是什么没有关系。

剩下的问题是一块小方格上的积分到底有多小。f 在 \(z_0\) 可导，意思是 \(f(z)=f(z_0)+f'(z_0)(z-z_0)+o(|z-z_0|)\)，末尾那一项比 \(|z-z_0|\) 还小。前两项沿闭合周线的积分都是零，因为 \(\oint dz=0\) 且 \(\oint z\,dz=0\)，能留下来的只有那个 o 项，它沿一圈的积分不超过「o(直径) 乘 周长」，比整块的面积还小得快。格子切细，所有小块的贡献加起来就压到零，而左边的 \(\oint_C f\,dz\) 与怎么切无关，于是它只能等于零。

单连通这条要求管的是切分能不能做成。区域里有洞时，绕着洞的那几块方格无论怎么切都不会整个躺在 D 里，总有一块压住洞，公共边抵消不干净，最里面会留下一圈绕洞的积分。区域没有洞，任意一条闭曲线都能在区域内连续收缩成一点，切分就能一路做到底。\(f(z)=1/z\) 在圆环 \(1/2<|z|<2\) 内处处可导，绕 \(|z|=1\) 一圈的积分却是 \(2\pi i\)，这个例子说明「处处可导」这一句不能单独用，还得看区域有没有洞。

柯西把积分限放到虚轴上

「当积分限取虚数值时，积分的值取决于所沿的路线。」

柯西《关于积分限为虚数的定积分的报告》，1825 年

这份报告 1814 年提交、1825 年刊出，第一次把复积分与积分定理写下来，当时还要求 f 的导数连续。古尔萨 1883 年免掉了这一条，莫雷拉 1886 年补上逆命题：f 只要连续、沿任意闭路的积分为零，它就是解析的。

三、原函数与路径无关

柯西定理最直接的用处是造原函数。设 f 在单连通区域 D 内解析，取定 \(z_0\in D\)，让 z 在 D 内动，定义 \(F(z)=\int_{z_0}^{z}f(\zeta)\,d\zeta\)。这个写法先得说明自己站得住：从 \(z_0\) 到 z 有无数条路，要证明每条路算出来是同一个数。理由很短，任意两条路合起来是一条闭路，柯西定理说沿它一圈为零，于是走第一条与走第二条的积分之差是零。

定理（原函数与牛顿-莱布尼茨公式）

设 f 在单连通区域 D 内解析，则 \(F(z)=\int_{z_0}^{z}f(\zeta)\,d\zeta\) 在 D 内解析，且 \(F'(z)=f(z)\)。对 D 内任意两点 \(z_0,z_1\)，积分与路径无关，并且

\[ \int_{z_0}^{z_1}f(z)\,dz=F(z_1)-F(z_0). \]

这件事在多元微积分里有现成的对应物。一个向量场沿路径的线积分与路径无关，当且仅当它是某个数量函数的梯度，那个函数叫势函数；这里的 f 相当于梯度场，F 相当于势函数，牛顿-莱布尼茨公式相当于势差。两边的条件形状也一样，多元那边要求旋度为零再加上区域没有洞，这边只写「f 解析」四个字，因为解析比旋度为零强，它把积分与路径无关的另一半也一起包了进去。

在单连通区域里，下面四条说法是同一件事：f 解析；f 沿区域内任意闭路的积分为零；f 的积分与路径无关；f 有原函数。考试里判断一个积分能不能用牛顿-莱布尼茨公式，问的就是这四条里的最后一条，而它由前三条任意一条给出。

柯西定理能不能反过来用

能，这就是莫雷拉定理。f 在区域 D 内连续、沿 D 内任意周线的积分为零，则 f 在 D 内解析。证法还是造 \(F(z)=\int_{z_0}^{z}f\,d\zeta\)，先验出 \(F'=f\)，再对 F 用柯西定理得 F 二阶可导，于是 f 作为 F 的导数也解析。这条路把「积分为零」与「解析」接成了等价的两件事。

四、多连通区域与桥

区域有洞时，柯西定理得改写。做法是把内外边界接成一条闭路：从外边界上一点出发，沿一条线段走进洞里，绕内边界走一圈，再沿同一条线段走回来，最后沿外边界剩下的部分回到起点。那条线段在图上叫桥，来回各走一次，方向相反，两段的积分一正一负互相抵消，剩下的大闭路就是「绕外圈」加「反向绕内圈」这两件事拼在一起。

定理（复合闭路定理）

设区域 D 的边界由外边界 \(C_0\) 与内部若干条边界 \(C_1,\dots,C_n\) 组成，f 在 D 内与这些边界上都解析。把 \(C_0\) 与各 \(C_k\) 都取逆时针方向，则

\[ \oint_{C_0}f(z)\,dz=\sum_{k=1}^{n}\oint_{C_k}f(z)\,dz. \]

沿外圈走一圈的值，等于沿里面每个洞各走一圈的值之和。

由此得到一条好用的推论，叫闭路变形原理：一条闭曲线在区域内连续变形，只要变形过程中不扫过 f 的奇点，积分值就不变。所以算 \(\oint\frac{f(z)}{z-a}dz\) 这类式子时，围住 a 的曲线长什么样不重要，把它换成以 a 为心、半径很小的圆最省事，圆上的参数式简单，分母也好处理。

五、柯西积分公式

柯西定理说解析函数沿闭路的积分为零，可被积函数里多一个分母 \(z-z_0\)，结果就不再是零，而且这个非零的数正好是函数在 \(z_0\) 处的值乘 \(2\pi i\)。柯西积分公式讲的就是这件事：区域内部的函数值，完全由边界上的值定下来。

定理（柯西积分公式）

设 f 在简单闭曲线 C 的内部与 C 上解析，\(z_0\) 是 C 内部一点，则

\[ \oint_C\frac{f(z)}{z-z_0}\,dz=2\pi i\,f(z_0). \]

推导只用闭路变形原理。以 \(z_0\) 为心作半径 \(\rho\) 的小圆 \(C_\rho\)，整个落在 C 内部，沿 C 的积分等于沿 \(C_\rho\) 的积分。在小圆上 \(z-z_0=\rho e^{i\theta}\)，积分变成 \(\int_0^{2\pi}f(z_0+\rho e^{i\theta})\,i\,d\theta\)，f 连续，\(\rho\to0\) 时被积函数一致趋于 \(f(z_0)\)，极限就是 \(2\pi i f(z_0)\)。奇点没有被消掉，它被绕了过去，多出来的那一份由 \(2\pi i\) 记在账上。同一段推导还读出一条平均值公式：\(f(z_0)=\frac{1}{2\pi}\int_0^{2\pi}f(z_0+re^{i\theta})\,d\theta\)，解析函数在圆心处的值，等于它在圆周上的平均值。

定理（高阶导数公式与柯西不等式）

在柯西积分公式的条件下，f 在 \(z_0\) 有各阶导数，且

\[ f^{(n)}(z_0)=\frac{n!}{2\pi i}\oint_C\frac{f(z)}{(z-z_0)^{n+1}}\,dz. \]

若 C 是以 \(z_0\) 为心、半径为 R 的圆，f 在 C 上满足 \(|f(z)|\le M\)，则 \(\left|f^{(n)}(z_0)\right|\le\dfrac{n!\,M}{R^{n}}\)。

高阶导数公式是怎么推出来的

把柯西公式里的 \(z_0\) 换成 \(z_0+\Delta z\)，两个积分相减，被积函数差出一项 \(\frac{\Delta z}{(z-z_0)(z-z_0-\Delta z)}\)。\(\Delta z\to0\) 时这一项一致地趋于 \(\frac{1}{(z-z_0)^2}\)，求导与积分可以交换次序，反复做 n 次就得到 n 阶导数的公式。

这条公式的后果比它本身重要。右边只用到 f 在边界那一圈的值，所以 f 在内部不只有一阶导数，还能一直求导下去，求一次导只是把分母的幂次加一。实变函数里可导一次不保证导函数连续，这里可导一次就自动可导无穷次，差别出在「从任何方向逼近都要给出同一个导数」这条要求上。

定理（刘维尔定理）

若 f 在整个复平面上解析且有界，即存在 M 使 \(|f(z)|\le M\) 对一切 z 成立，则 f 恒等于一个常数。

把它用在 \(1/p(z)\) 上就得到代数基本定理。设 \(p(z)=a_nz^n+\cdots+a_0\)，\(n\ge1\)，假设 p 在复平面上没有零点，则 \(1/p\) 是整函数，而 \(|p(z)|\to\infty\) 又保证 \(1/p\) 有界，刘维尔定理说这个有界的整函数只能是常数，于是 p 也只能是常数，与 \(n\ge1\) 矛盾。所以 p 至少有一个根，除掉这个根再对商用一次同样的论证，就凑够 n 个根。

柯西积分公式还留下一句话要好记：解析函数在区域内部没有自由，边界上一圈值定死了里面的一切。同一个函数在两条不同曲线上的积分只差一份，差多少由两条曲线之间有几个奇点决定，第五章的留数就是专门算这一份的。

怎么算

  • 先看奇点在哪。被积函数在闭路围成的区域内处处解析，直接写零，不用算。
  • 奇点在内部就换小圆。用闭路变形原理把复杂曲线换成以奇点为心的小圆，半径取方便算的。
  • 参数式优先选圆心形式。\(z=z_0+re^{i\theta}\) 时 \(dz=ire^{i\theta}d\theta\)，分母同时化简。
  • 方向要跟题目一致。顺时针的闭路等于逆时针的结果加一个负号，漏掉符号是这一章最常见的错。
  • 分段光滑的曲线分段算。每一段单独写参数式，注意接点处方向连续。
  • 估积分用 ML。M 取 |f| 在曲线上的最大值，L 是弧长，估出来的是上界，不要写成等号。
1/z 在圆环里为什么没有原函数

\(1/z\) 在 \(0<|z|<2\) 内处处解析，可它在这个环域里没有原函数。若 \(F'=1/z\)，沿正向单位圆走一圈，积分既是 \(2\pi i\)，又等于 \(F(1)-F(1)=0\)，矛盾。原函数的存在性靠的是区域单连通，这条性质在圆环里断掉了。

例题

例 1　沿两条路径计算 \(\int_C\bar z\,dz\)：一条是从 0 到 \(1+i\) 的直线段，另一条是从 0 到 1 再到 \(1+i\) 的折线，比较结果。

直线：\(z=(1+i)t\)，\(\bar z=(1-i)t\)，\(dz=(1+i)dt\)，积分为 \(\int_0^1 2t\,dt=1\)。折线：0 到 1 上是 \(1/2\)，1 到 \(1+i\) 上是 \(1/2+i\)，合计 \(1+i\)。两条路不相等，因为 \(\bar z\) 不解析。

例 2　计算 \(\oint_{|z-1|=1}\dfrac{dz}{z^2-1}\)。

把被积式写成 \(\dfrac{1/(z+1)}{z-1}\)，圆内只有奇点 \(z=1\)，\(f(z)=1/(z+1)\) 在圆内解析。由柯西积分公式，积分等于 \(2\pi i f(1)=2\pi i\cdot\frac12=\pi i\)。

例 3　计算 \(\oint_{|z|=2}\dfrac{e^z}{(z-1)^2}\,dz\)。

被积式是 \(f(z)=e^z\) 除以 \((z-1)^2\)，\(z=1\) 在圆内。高阶导数公式取 \(n=1\)，积分等于 \(2\pi i f'(1)=2\pi i\,e\)。

习题

A 档 巩固定义与基本计算，每题五分钟内

1. 用参数法计算 \(\int_C\bar z\,dz\)，其中 \(C:z=2e^{i\theta}\)，\(0\le\theta\le\pi\)。

看答案

\(\bar z=2e^{-i\theta}\)，\(dz=2ie^{i\theta}d\theta\)，积分为 \(\int_0^\pi 4i\,d\theta=4\pi i\)。

2. 用估值不等式估计 \(\left|\oint_{|z|=2}\dfrac{dz}{z^2-1}\right|\)。

看答案

在 \(|z|=2\) 上 \(|z^2-1|\ge3\)，故 \(|1/(z^2-1)|\le1/3\)，弧长 \(4\pi\)，估计值不超过 \(4\pi/3\)。

3. 计算 \(\oint_{|z|=1}\dfrac{dz}{z-2}\)。

看答案

奇点 2 在圆外，被积函数在闭圆盘上解析，由柯西积分定理值为 0。

4. 计算 \(\oint_{|z|=2}\dfrac{dz}{z-1}\)。

看答案

取 \(f(z)=1\)，奇点 1 在圆内，柯西积分公式给出 \(2\pi i f(1)=2\pi i\)。

5. 用牛顿-莱布尼茨公式计算 \(\int_0^{1+i}z^2\,dz\)。

看答案

原函数 \(z^3/3\)，代入得 \((1+i)^3/3=(-2+2i)/3\)。

6. 分别计算 \(\oint_{|z|=1}z^{-1}dz\) 与 \(\oint_{|z|=1}z^{-2}dz\)，并解释两者为什么不同。

看答案

前者 \(2\pi i\)，后者 0。\(z^{-2}\) 有原函数 \(-1/z\)，闭路积分为零；\(z^{-1}\) 在去心区域没有原函数，只能靠柯西公式算。

B 档 综合题，接近期末与考研难度

1. 计算 \(\oint_{|z|=2}\dfrac{z+1}{z^2-1}\,dz\)。

看答案

被积式在 \(z\ne-1\) 处等于 \(1/(z-1)\)，\(z=-1\) 是可去奇点。圆内只剩奇点 1，积分为 \(2\pi i\)。

2. 计算 \(\oint_{|z|=2}\dfrac{e^{2z}}{(z-1)^3}\,dz\)。

看答案

取 \(n=2\)、\(f(z)=e^{2z}\)，\(f''(z)=4e^{2z}\)，积分为 \(\frac{2\pi i}{2!}\cdot4e^2=4\pi i\,e^2\)。

3. 设 f 在区域 D 内解析且 \(|f(z)|\) 是常数，证明 f 为常数。

看答案

记 \(|f|=c\)。\(c=0\) 时 f 恒为零；否则 \(u^2+v^2=c^2\)，两边对 x、y 求偏导，代入柯西-黎曼方程得 \(u_x=u_y=0\)，故 f 为常数。

4. 设 f 为整函数且 \(|f(z)|\le|z|\) 对一切 z 成立，证明 \(f(z)=az\) 且 \(|a|\le1\)。

看答案

f 在 \(|z|\le R\) 上满足 \(|f|\le R\)，柯西不等式给 \(|a_n|\le R^{1-n}\)，令 \(R\to\infty\) 得 \(n\ge2\) 的系数全为零；再由 \(|f(0)|\le0\) 得 \(f(0)=0\)，于是 \(f(z)=az\)，\(|a|\le1\)。

C 档 拓展与历史原题

1.（柯西，1825）这份报告里的命题是：f 在矩形区域上解析，则沿矩形边界的积分为零。说明这个结论怎么推到任意闭曲线上去。

看答案

用折线逼近任意闭曲线，折线围成的区域切成有限个矩形，每个矩形的积分为零，内部边成对相消，故沿折线的积分也为零。折线逼近时积分连续地趋于原曲线上的值，于是任意闭曲线的积分都是零。

2. 用柯西积分公式计算 \(\oint_{|z-a|=r}\dfrac{dz}{z-a}\)，并说明换成另一条不绕其他奇点的闭路后答案为什么还是 \(2\pi i\)。

看答案

取 \(f\equiv1\)，公式给出 \(2\pi i\)。换曲线时用闭路变形原理，只要变形不扫过 a 与别的奇点，积分值不变；扫过别的奇点则按复合闭路定理把那一份另计。

3.（刘维尔）用刘维尔定理证明代数基本定理。

看答案

若 p 没有零点，则 \(1/p\) 为整函数；\(|p(z)|\to\infty\) 保证它有界，刘维尔定理说它是常数，于是 p 为常数，与次数 \(n\ge1\) 矛盾。

思考题 不设标准答案，只给提示

1. 柯西定理的条件里，单连通是说区域没有洞；如果一条闭路绕过的奇点在区域之外，定理成立吗？把「区域」与「闭路围成的内部」分开想一想。

看提示

条件说的是 f 在 D 内解析、C 在 D 内。奇点若落在 C 的内部却不在 D 内，C 围住的那块就不属于 D，D 也就不是单连通的，定理的前提没满足。

2. 估值不等式 \(\left|\int_C f\,dz\right|\le ML\) 什么时候取等号？

看提示

要 \(|f|\) 在 C 上恒等于 M，且所有小向量同向，也就是 f 的辐角沿 C 不变。一般曲线上两者凑不齐，所以这个不等式只用来估上界。

3. 柯西积分公式说内部的值由边界值决定，为什么实际计算时不直接给边界数据，仍要回到被积函数？

看提示

边界值必须是解析函数在整条曲线上的精确值，一点误差就会传进内部，而题目给的通常是 f 的表达式。公式的用法是反过来的：把内部的 f(z_0) 换成一圈边界积分来算。
